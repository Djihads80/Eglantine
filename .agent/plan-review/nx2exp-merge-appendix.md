Read-only analysis, 2026-11-07. Trial merge: `git merge-tree --write-tree HEAD upstream/nx2-experimental` with HEAD a1062b1d18 and upstream db093d7325, giving tree `d953b19df3` and merge base `0857e8b4a7`. See conflict markers with `git show d953b19df3:<path>`. Each file line reads [resolution/risk] detail | risk | verify. Line numbers are in the merged (trial) file.

##### AREA shader
SUMMARY: 17 conflicted files in this area. Most are the same work done twice, ported under different hashes on each side (HMMA 9befa0a11b = e88024e6b0, which differ only in whitespace; untracked atomics 01783ceb29 = 6b934346d7; loaded pointers f1db39100b = 4ac9e703fe; mesh points e45373d781 = 743d5bbaed; competing loaded pointers f52fb9cd40 = a51a69fbfb; subgroup broadcast ff772eb8fb = c58d474d32; and the Ocarina lowering series aadca53092/efd03df47b/dc3e912fb7/a6dea8a75d/8424eeb253/f918505146/502e6e2f24, which upstream has as 9a69d8eaf0/582ecc4568/29ed33831a/223c752f44/19e25d0cfb/f1a5c6e04f/edf4eacc7d). Ours is usually the superset, because we have later commits on top: global ATOM.CAS (4950e91f33, 9adfd1b28a), cooperative HMMA (0aeaec747c), the K8 unroll (767f9b36fe), the quartet-pair borrowing in register pressure, the TLD4.B second descriptor buffer (979991233b), SURED data shadowing (13e12a6ce9), aligned handle reads (a35ccb90a9) and the jpkto CAS-retry commits.

Upstream brings these new things:
- Default-on A/B env gates: EGLANTINE_CAS_RETRY_FIX, EGLANTINE_DEPTH_FLOAT_FIX, EGLANTINE_SSBO_ALIGN_FIX, EDEN_NX2_LOWER_EXTENDED, EDEN_NX2_WIDE_COMPUTE_SSBOS.
- The SSBO misaligned-access split (18106bdf49).
- The AMD fragment-shuffle flag.
- Compute-only 64 SSBOs (de4ed9d9d7).
- vulkan_mesh.bin through with_mesh_state (bc121caf3e).
- The Lichii debug-server includes (7602efc518).
- MKW water fallback includes (39a33c4a78).
- The re-landed Star Fox lowering (587633debe): SUATOM 0x593, SHF.R.HI, TXD 0xf6c and TLD4 bounds. Our side has it reverted through e87ad31068. Upstream-exp has it again and also brings its tests in ampere_gradient.cpp.

Default behaviour of every upstream gate equals ours, so taking upstream's gated form changes nothing by default. Our CAS is already unconditional. Our depth float fix is unconditional. Our extended lowering is unconditional.

None of these files touch Nx2Perf. Fog, flashes, frames_ahead and present_one_ahead are not involved.

Overall: about 10 files are mechanical (take-ours or take-theirs). The real decisions are these:
- (a) Which null-slot rebuild implementation to keep: ours 92c214fe86 or upstream 688c6fa7d8. This must match vk_pipeline_cache and vk_compute_pipeline.
- (b) Which mesh disk-cache format to use, with_mesh_state or ours. This must match the vk_pipeline_cache resolution and the CACHE_VERSION choice.
- (c) Graphics SSBO limit: 32 (upstream) or the device limit (ours). This must match buffer_cache_base.
- (d) Star Fox SURED/SUATOM and TLD4 bounds against upstream's ampere_gradient tests.

Suggested build-and-test order after resolving: build yuzu, yuzu-cmd and tests. Run tests.exe "[ampere]", "[tensor]", "[global_memory]" and "[video_core]", the full suite including nx2_perf. Then do the lab check: OoT Kokiri spawn and walk, then Hyrule Field and Castle Town (grass, bushes, distant terrain), on an empty shader cache and again on the second run. Grep the log for "Rebuilding compute program", "storage buffers", "native .* mode" rejections, "Global atomic compare-exchange" and NotImplemented. Compare Nx2Frame median and worst frame times against the current local-combined.
